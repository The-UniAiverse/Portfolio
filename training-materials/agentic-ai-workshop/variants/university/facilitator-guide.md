# Facilitator guide — AI, RAG & Agents — Student Bootcamp (2 days) / Faculty Development (1 day)
**Audience:** Undergraduate / postgraduate students (CS, IT, MBA, commerce) in batches of up to 40 with a TA; or faculty  ·  **Duration:** 2 day(s)  ·  **Deck:** `deck-university.pptx` (42 slides, speaker notes on every slide)

## Tone
Energetic, portfolio-driven. Every lab produces something for GitHub. Interview questions woven in from uniAI Quest.

## Platform
Free tiers: Google Colab notebooks (code track), Dify/NotebookLM (no-code track). Optional: student credits on a cloud.

## Before the day
- Computer lab or own laptops with browser
- GitHub accounts
- Python installed for the code track
- Run `python ../../demos/run_all.py` on the delivery laptop — it must print ALL DEMOS OK
- Replace `demos/sample_docs/` with the client's documents where allowed

## Run of show
Follow the master run sheet (`../../facilitator-guide.md`) for timing and demo cues, using only the slides in this deck. Variant-specific modules below are inserted where their heading says.

### Why this matters for your first job (10 min, after “How the two days run”)
Show three real job posts asking for RAG / agents / evals. 'The person who can explain why the bot is wrong is rarer than the person who can call an API.'

### Interview round: RAG (20 min, after “answer is wrong”)
Run three uniAI Quest interview challenges live (rag-70, cost-estimate, injection). Pairs answer, room votes, reveal 'what interviewers listen for'.

### Portfolio project: build it like production (20 min, after “safety rails”)
Definition of Done for the capstone: eval set in repo, README with architecture diagram, cost estimate, one injection test. This is what you show in the interview.

### Certificates and next steps (10 min, after “Five things”)
AI Aware certificate for attendance + quiz; AI Practitioner for a capstone that meets the DoD within two weeks. Course Finder for the path. uniAI Quest free tier to keep practising.


## Labs in this variant
- **LAB0** — Hour-one win on provided sample docs
- **LAB1** — Cost a chatbot for the college (admissions FAQ)
- **LAB2** — Code track: Colab notebook — chunk, embed, hybrid, rerank, score. No-code track: Dify
- **LAB3** — Agent with three tools (course catalogue search, timetable lookup, draft email) with caps
- **LAB5** — Capstone plan: a RAG or agent project for the college or a local business, with eval set and cost

## Assessment
Quiz (uniAI Quest topics: ai-basics, rag, agents, tokens-cost) + capstone reviewed against the Definition of Done

## Done when
Every student has a GitHub repo with a working RAG notebook or Dify app, a test sheet and a cost estimate; top capstones presented.
