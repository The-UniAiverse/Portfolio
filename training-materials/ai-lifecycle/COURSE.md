# AI Development & Deployment Lifecycle — Course Plan (2 × 4h)
**Audience:** engineers, PMs, delivery leads. **Promise:** run an AI project from discovery to monitored production with the right gates — the uniAIverse standard lifecycle.

## The lifecycle (with gate criteria)
| Phase | Owner (per role doc) | Exit criteria |
|---|---|---|
| 1. Discovery & business need | Strategy (Sarfi) | Problem statement, success metric, constraints, data available (yes/no/partly) |
| 2. Solution definition | Strategy + GenAI (Sarfi/Harsh) | Recommended approach, scope, feasibility, eval plan, cost range |
| 3. Architecture & design | GenAI + Eng (Harsh/Sahil) | Architecture, integrations, data/LLM approach, security review |
| 4. Build | GenAI + Eng | Working solution, tests, eval set ≥ baseline, docs |
| 5. Data / model / operationalisation | Strategy/MLOps (Sarfi) | Pipelines, monitoring, versioning, rollback |
| 6. Validation & governance | Strategy (Sarfi) | Quality, risk review, compliance sign-off, acceptance criteria met |
| 7. Deployment & handover | Eng + MLOps | Deployed, runbook, owner named, training done |
| 8. Optimise & scale | Relevant owner | KPIs tracked 90 days, backlog of improvements |

## Day 1: phases 1-4 with a worked example. Day 2: phases 5-8 + a lab where teams run a mock project through all gates.
**Handouts:** gate checklist · Definition of Done · intake questionnaire · risk classification card.
